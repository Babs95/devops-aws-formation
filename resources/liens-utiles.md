## 🛠️ Outils et Extensions

### AWS CLI
```bash
# Installation
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
unzip awscliv2.zip
sudo ./aws/install

# Documentation
https://docs.aws.amazon.com/cli/
```

## 🗓️ Planification Examen

**AWS Training and Certification**
- URL : https://www.aws.training/
- S'inscrire pour passer l'examen

**PSI vs Pearson VUE**
- PSI : En ligne (chez vous avec webcam)
- Pearson VUE : Centre de test physique
- **Recommandation** : Centre de test (moins de risques techniques)

**Prix Examen**
- Developer Associate : 150 USD
- Solutions Architect Associate : 150 USD

**Durée Examen**
- 130 minutes
- 65 questions
- Passing score : ~720/1000 (~72%)

**Validity**
- Certificat valide 3 ans
