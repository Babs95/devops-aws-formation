## 📖 Comment Utiliser les Modules

Chaque module (semaine) contient :

1. **README.md** : Guide complet du module avec
   - Objectifs d'apprentissage
   - Partie théorique (concepts clés)
   - Partie pratique (labs hands-on)
   - Intégration DevOps
   - Questions types d'examen
   - Checklist de validation

2. **labs/** : Code et instructions pour les labs pratiques

3. **quiz/** : Questions de révision pour ce module

## 💡 Comment Travailler avec les Modules

### Ordre Recommandé

1. **Lire le README du module** (15-30min)
2. **Regarder les vidéos** du cours (Udemy/Skill Builder) (3-5h)
3. **Pratiquer les labs** hands-on (5-10h)
4. **Réviser avec les QCM** (1-2h)
5. **Valider la checklist** (auto-évaluation)
6. **Passer au module suivant** seulement si score QCM > 75%

### Temps Hebdomadaire

- **Minimum** : 10h/semaine (programme sur 25-30 semaines)
- **Recommandé** : 15-20h/semaine (programme sur 16-20 semaines)
- **Intensif** : 25-30h/semaine (programme sur 12-15 semaines)
